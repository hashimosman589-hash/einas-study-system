# نظام إيناس للمذاكرة الذكية

نظام ويب عربي متكامل (RTL) لإدارة المذاكرة بمساعدة الذكاء الاصطناعي: رفع المحاضرات، تحليلها، استخراج الملخصات والأسئلة، إنشاء الاختبارات، وتصحيحها مع تحليل نقاط الضعف وتوصيات مذاكرة.

## سير العمل
رفع المحاضرة ← تحليل AI ← استخراج الأسئلة ← الملخص ← الاختبار ← التصحيح ← تحليل مستوى الطالب ← خطة المراجعة.

## التقنيات
| الطبقة | التقنية |
|---|---|
| Frontend | React 18 + Vite + Tailwind CSS (RTL / دارك-لايت) |
| Backend | Node.js + Express |
| Database | SQLite عبر وحدة `node:sqlite` المدمجة (بلا تبعيات خارجية) |
| AI | OpenAI-compatible API (اختياري) + محلل محلي احتياطي يعمل بدون مفتاح |
| Parsing | pdf-parse / mammoth / xlsx |

## البنية
```
نظام-ايناس/
├── server/          # Express REST API + SQLite
│   ├── src/
│   │   ├── routes/  # auth, lectures, exams, results, analytics
│   │   └── lib/     # ai, localAnalyzer, parser, auth
│   ├── data/        # قاعدة البيانات والملفات المرفوعة (تُنشأ تلقائيًا)
│   └── scripts/     # test-backend.js (اختبار تكاملي)
├── client/          # React SPA (Vite)
└── package.json     # أوامر root
```

## التشغيل السريع

### الخيار 1: وضع التطوير (واجهة Vite + خادم)
```bash
npm install            # في المجلد الجذر
npm run install:all    # تثبيت server و client
npm run dev            # يشغّل الخادم (5000) والواجهة (5173) معًا
```
- الواجهة: http://localhost:5173
- API: http://localhost:5000/api

### الخيار 2: وضع الإنتاج (الواجهة المبنية يخدمها Express)
```bash
npm run build          # يبني الواجهة إلى client/dist
npm start              # يشغّل الخادم على http://localhost:5000
```
ثم افتح http://localhost:5000 — سيرى النظام الواجهة المبنية والـ API في نفس العنوان.

> ملاحظة: أول تشغيل أنشئ حسابًا من صفحة "حساب جديد".

## AI API (اختياري)
عدّل `server/.env` واجعل:
```
AI_API_KEY=sk-...
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```
إن تُرك المفتاح فارغًا، يعمل النظام بالمحلل المحلي الاحتياطي (يستخرج النقاط والمصطلحات ويبني أسئلة) فتعمل كل الأقسام دون إنترنت.

## الاختبار التكاملي للواجهة الخلفية
```bash
cd server
node scripts/test-backend.js
```
يفحص: تسجيل دخول، رفع محاضرة، تحليل، توليد اختبار، تصحيح، توصيات، ولوحة تحكم.

## الأقسام
- **لوحة التحكم**: إحصائيات، متوسط الدرجات، نسبة الإنجاز، نقاط الضعف، منحنى التقدم.
- **المحاضرات**: رفع PDF/Word/Excel/نص + تحليل AI تلقائي.
- **الملخصات والتحليل**: ملخص، أهم النقاط، سؤال وجواب، مصطلحات، مواضيع للمراجعة.
- **الاختبارات**: توليد MCQ + صح/خطأ بعدد ووقت محدد، مؤقّت، تصحيح فوري.
- **الدرجات والملاحظات**: الدرجة والنسبة، تحليل الأخطاء، توصيات AI للمذاكرة.
